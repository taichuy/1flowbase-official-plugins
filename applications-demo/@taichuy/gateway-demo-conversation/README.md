# Gateway Demo Conversation

这是从 Gateway Demo 拆出的可选 `1flowbase` 对话 AgentFlow，不随 Docker 安装网关工作台。先在目标工作区配置流程所需的 `anthropic`、`openai`、`gemini` 和 `deepseek` 供应商及所选模型，再从扩展中心安装。已经有这套对话应用的工作区无需重复安装。本模板不包含页面、供应商配置或密钥。

This optional template contains the `1flowbase` conversation AgentFlow, separate from the Docker-bundled Gateway Demo workbench. Configure the workflow's `anthropic`, `openai`, `gemini`, and `deepseek` providers and selected models in the target workspace before installing it from the extension center. Workspaces that already have the conversation application do not need to install it again. The package ships no pages, provider configuration, or secrets.
